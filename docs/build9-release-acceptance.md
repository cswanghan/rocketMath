## 本次行为与内容

选择题点击选项后立即判题并展示正误反馈和解析，不再要求第二次点击“检查”。答对或两次答错揭示答案后保留“继续”，不会自动跳题；第一次答错后保留错误反馈、提示及解析，选项锁定，用户点击“再试一次／Try again”后才重新开放选择。连续点击同一错误选项不会额外扣次或累计错误；重复、过期回调及无效选项不再重复判题或计分。填空、多步题及口算数字输入仍保留明确确认。

本次只调整选择题 UI 与提交状态管理，未修改练习引擎、正确性算法、计分算法、随机选择、掌握阈值或历史进度结构。中英文重试文案均已覆盖；错误反馈与解析保持可见。
