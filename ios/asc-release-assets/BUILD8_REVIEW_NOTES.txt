Xingya 1.0.0 (8) — mathematics-only iOS release

Oral-math practice for Grades 3–9 now contains 2,056 questions, retaining existing question IDs and progress structure. This includes Grade 4 answer variety, signed-number entry in practice/races, and a “More fluency practice” entry for Grade 7 rational multiplication/division. The engine, mastery thresholds and scoring are unchanged. Mathematics content supports Chinese and English; the separate Web Chinese/English subject modules are not native iOS features.

Build 6 Apple sign-in and subscription fixes are retained: fresh authorization requests, retained pending state, silent cancellation, verified Apple tokens, and the deployed backend key-request compatibility fix. Empty/transient StoreKit catalog responses retry with backoff; Account reappearance reloads, and localized Retry is available. A secondary refresh failure does not undo server-confirmed entitlement binding.

Review paths:
1. Select a grade and complete the warm-up if shown. Practice and on-device reports are free, work offline, and require neither login nor a subscription.
2. Apple sign-in: Me → Account → Sign in / Create account → Continue with Apple. Alternatively use the username/password supplied in App Review Information; credentials are not repeated here.
3. Subscription: sign in, then Me → Account → Monthly membership. Product: com.hanwang.xingya.premium.monthly. Name and price come from StoreKit. Tap Retry or revisit Account if the catalog is unavailable.
4. After a Sandbox purchase, confirm active membership following server verification. Restore purchases using the original Xingya account. Canceling purchase or restore authentication should return silently.
5. Account → Sync now provides manual cloud sync. Cloud sync and Me → Parent → remote AI summary require active membership; remote results require a server response. Local analysis stays free. Membership includes Manage subscriptions, renewal terms, privacy policy and the Apple Standard EULA. Deleting a Xingya account does not cancel its Apple subscription.
6. For signed practice, select Grade 7 → Home → More fluency practice → Mental arithmetic: multiplication and division of rational numbers → Fluency or Race. Use ± for negative answers. The sign key applies to the whole track, not the current answer.
